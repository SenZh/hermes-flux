## 2. 已完成并验证

### 2.1 对号语义

旧实现：`active` 用绿底白对号，`ready` 用绿色空心对号。用户问"有什么区别"，说明两套视觉本身就是歧义。
现在：所有已勾选格统一用 `bg-primary text-primary-foreground` 对号；当前模型改用头像 `ring-2 ring-success` + 名称加粗；面板级图例写「勾选 = 已配置 · 绿环 = 当前模型」。

关键文件：`packages/ui/src/components-react/settings/ProvidersAdminPanel.tsx`

### 2.2 查看模型改弹框 + 复用模型行

- 删除行内展开列表与 `UseProviderDialog`。
- 新增 `ModelPickerDialog`：点模型即设为当前模型；`confirm_required` 时弹框不关，显示网关原文与「仍然设置」；失败保窗并显示原因。
- 新增 `ModelOptionRow`：品牌 SVG 图标 + core `parseModelDisplay` 计算出的完整可读名；不直出 ID；不再重复叠 `Fast`/`Q4` 标签（名字里已经包含）。
- 新增 `packages/ui/src/lib/modelPresentation.ts`：厂商 → 品牌映射、provider 兜底、`presentModel`。
- 新增测试 `packages/ui/__tests__/model-presentation.test.mjs`（覆盖 15 个厂商、大小写、unknown 兜底）。
- 弹框打开时把焦点移入自身，Esc 只关弹框，不再冒泡关掉整个设置中心。

### 2.3 编辑页默认模型改下拉

- `ModelPickerField`：有模型列表时显示「图标 + 计算名」按钮，点击打开 Radix `Menu`（Portal + `z-[1200]`，高于设置中心 `z-[1000]`）；下拉内保留「手动输入模型 ID」逃生口。
- 没有模型列表时退化为普通输入框，提示"测试端点后这里会列出可选的模型"。
- 下拉内部模型列表单独滚动，手动入口固定在底部，不被长列表挤出折叠线。

### 2.4 取消后重新勾选：自动复制密钥

- `providerAdminRest.revealEnv(profile, key)`：`POST /api/env/reveal`，body `{ key, profile }`，不把变量名放 URL。
- `providerAdminController.resolveEndpointKey(id, sources)`：按配置集合遍历其它成员，读端点行的 `api_key_preview`，只接受严格 `${ENV_VAR}`；调 reveal 取明文后返回。
- 判别式返回：`{ok:true,key,source}` / `{ok:false,reason:'no-readable-key'}` / `{ok:false,reason:'transport',message}`。
- `index.ts` 的 `case 'attach'`：先复制；`no-readable-key` 才返回 `needsKey:true` 让 UI 弹输入；`transport` 原样报错，不伪装成"请重输密钥"。
- `AgentBindingGrid.attach`：先调一次无密钥 attach，只有 `needsKey` 才展开密钥输入。
- attach / detach / logout 成功后 `await reloadProviderCatalog()`，回读完成前保持 pending，避免"点了没反应"。
- 网关取证写在 `docs/changes/2026-11-11_provider-binding/design.md` §3.3（0.22.5 `hermes_cli/web_routers/config_env.py`）。

### 2.5 头像格与列数一致性

- 移除 80×60 方框卡；成员格改为 64px 轨道、44px 头像、名称在下方，勾选徽标叠在头像右下角，当前模型用 success 环，读取失败用虚线红边 + 红点 + 可见原因。
- 名称预算与 64px 轨道对齐：`PROFILE_LABEL_MAX_UNITS` 由 8 调整为 10（5 汉字 / 10 半角），`xiaofawang` 不再被截成 `xiaofaw…`；超长名按 9 单位 + `…` 截断，完整名留在 title。宽字母与 12px 大字号档由 CSS `truncate` 兜底。
- 添加端点弹框的「保存时配置到」成员列表抽出 `FanOutMemberList`：全宽列表用 24 单位兜底（常规名不截断），`title` / `aria-label` 保留全名，并有独立 SSR 测试。
- 网格从"标题 + 动作按钮之间"移到它们下方，横跨整行。之前自定义端点行 3 个按钮、订阅行 2 个按钮，左列宽度不同，导致同一份名单排出 4 列 / 5 列；现在所有行同宽。
- `agent-grid`：`repeat(auto-fill, 64px)`、`gap: 12px 8px`、`justify-content: start`。**只换行，不横向滚动**。
- 图例提升到面板级只出现一次；订阅行标题改「生效于 · 全部 Agent（只读）」，hint 改「订阅登录一次即对所有 Agent 生效，无需逐个勾选」。

### 2.6 其他修复
