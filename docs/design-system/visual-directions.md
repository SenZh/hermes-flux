# Hermes Flux 首批 4 套顶级美学视觉方案 (Visual Directions)

> **设计哲学**：
> “高级感不是堆砌花哨的渐变，而是对**黑色的层次、光的衰减、微距边框与呼吸流动感**的极致掌控。”
> 
> 针对高端极客、开发者与设计挑剔型用户，我们精细打磨了以下 4 套视觉方案：

---

## 方案 1：黑曜琥珀 (Obsidian Gold) — 【沉稳旗舰 · 电影级黑金】

* **灵感来源**：高端音响（如 Devialet / Leica）、瑞士名表表盘、电影《沙丘》工业美学。
* **视觉特征**：
  * **底色**：不是死板的纯黑 `#000000`，而是微带暖调深渊感的 `#080808`；
  * **卡片与边框**：卡片采用 `#121212`，边缘是一条极其克制、0.5px 的精密微光暗金/深灰边框（`#27272A`）；
  * **光晕高亮**：跑模型时，状态球泛出极其细腻的**琥珀暖金光晕 (`#FFBF00`，外圈呼吸衰减至 15% 透明度)**；
  * **气场**：极度沉稳、昂贵、内敛、耐看。适合深夜长时间码字与深度调试，绝对不伤眼。

---

## 方案 2：赛博银翼 (Titanium / Cyber-Frost) — 【极致科技 · 冷冽纯钛】

* **灵感来源**：Apple 原生钛金属、极简科技产品（如 Teenage Engineering）、《银翼杀手2049》。
* **视觉特征**：
  * **底色**：带有微弱蓝灰偏色的金属暗黑 `#0B0D11`；
  * **光晕高亮**：**冰蓝流光 (`#00F2FE` ➔ `#4FACFE`)**；
  * **材质感**：大量运用 **高级亚克力毛玻璃（Frosted Glass）** 与微弱的噪点晶体磨砂感（Backdrop Blur 24px + 噪点纹理）；
  * **排版**：极度工整，状态栏、命令提示符带有强烈的航天仪表盘精密感；
  * **气场**：冷峻、极客、未来科技感十足，年轻人第一眼会被惊艳。

---

## 方案 3：深邃紫域 (Astral Void) — 【灵境思维 · 赛博暗紫】

* **灵感来源**：OpenAI / Linear 经典暗紫、星系暗物质、神秘智能体共鸣。
* **视觉特征**：
  * **底色**：宇宙真空般的玄黑 `#09080E`（隐隐透出暗紫色深邃渐层）；
  * **光晕高亮**：**霓虹暗紫 (`#A855F7`) 与 极光玫红 (`#EC4899`)**；
  * **思维链动效**：当 Agent 在进行深层思考（Reasoning / Think 阶段）时，输入框顶部有一道如极光般缓慢流转的光轨；
  * **代码高亮**：专门调配的 Synthwave 暗夜配色，代码注释呈灰粉色，关键字呈高亮霓虹紫；
  * **气场**：前卫、梦幻、富有灵性，极受 AI 深度研究者和极客设计师喜爱。

---

## 方案 4：纸墨微光 (Paper & Ink / Mono Minimal) — 【极致克制 · 纯粹极简】

* **灵感来源**：电子墨水屏、日本禅意设计（MUJI）、现代瑞士国际主义平面排版。
* **视觉特征**：
  * **底色**：高雅灰调暗夜 `#101010`，无任何刺眼大红大绿；
  * **核心强调**：彻底抛弃浓重的光效与彩色外光晕，**依靠极其严格的字体字重（Light / Regular / Semi-Bold）、字间距与留白（Negative Space）来体现层次**；
  * **高亮色**：只有纯白 (`#FFFFFF`) 与中度明灰 (`#8E8E93`)，唯一有色彩的是微弱的通知原点；
  * **气场**：不喧宾夺主，像在阅读一份精美的现代设计期刊，让人的注意力 100% 聚焦在代码和文字本身。

---

## 四套方案关键视觉参数对比

| 方案名称 | 主底色 (Base) | 主强调色 (Accent) | 质感倾向 | 最适配人群 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 黑曜琥珀 (Obsidian Gold)** | `#080808` | 琥珀金 `#FFBF00` | 金属哑光 / 高端名表 | 追求奢华沉稳、深夜长时间工作的工程师 |
| **2. 赛博银翼 (Titanium Frost)** | `#0B0D11` | 冰晶蓝 `#00E5FF` | 钛金磨砂 / 航天仪表 | 极客、喜欢未来科技硬核感的玩家 |
| **3. 深邃紫域 (Astral Void)** | `#09080E` | 极光紫 `#A855F7` | 灵气流动 / 极光光轨 | 喜欢 Linear 风格、强调设计前卫的创造者 |
| **4. 纸墨微光 (Mono Minimal)** | `#101010` | 高光白 `#FFFFFF` | 极简留白 / 禅意阅读 | 极简主义者、纯文字与代码深度专注者 |
