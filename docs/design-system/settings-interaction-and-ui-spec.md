# Hermes Flux 设置中心交互与 UI 终极设计规范 (Settings Interaction & Visual Design Spec)

> **定位说明**：本文档确立了 **Hermes Flux**（桌面端 Electron、Web、移动端 iOS/Android Capacitor 8）设置中心（Settings Hub）的完整交互架构（UX Architecture）与高保真视觉设计规范（UI Spec）。
> 本规范严格遵循 Monorepo 架构分层、29-color Design Tokens 体系与苹果级极客美学，作为后续前端组件库实现（`packages/ui`）与平台挂载的唯一定稿基线。

## 一、 核心交互状态机与四大杀手级体验 (Key Interaction Invariants)

### 1.1 三级作用域级联指示器 (Scope Selector & Cascade Indicator)
为了解决“用户到底在改全局默认还是在改某个专职数字员工（如架构师老王）”的心智混乱，设置中心确立**“物理实体级联状态机”**：
1. **左上角实体切换器**：
   - 常驻下拉胶囊：`[ 🌐 全局配置 (Global) ▾ ]`；
   - 点击可切换为具体专职 Bot：`[ 🤖 架构师 · 老王 ]`、`[ 🤖 前端 · 小张 ]`；
2. **三态指示徽章 (State Badges)**：
   - **继承态 (Inherited)**：右侧显示浅灰低饱和徽章 `[ 继承自全局 ]`，输入框显示浅灰占位符；
   - **覆写态 (Overridden)**：当用户修改了该项使其与全局脱钩时，自动切换为琥珀高光徽章 `[ ⚡ Bot 已覆写 ]`，紧邻出现恢复小按钮 `[ ↺ 还原为继承值 ]`；
   - **只读隔离态 (Isolated)**：对于“全局网络代理”、“Nous 订阅套餐”等仅限全局的项，当处于 Bot 视角时自动置灰并提示 `仅限全局配置修改`。

### 1.2 0 延迟即时全文搜索与高亮脉冲 (Instant Search & Pulse Highlight)
- **全局触发**：在设置内按 `Cmd + F` 或直接在顶栏搜索框键入字符；
- **智能索引**：前端本地建立倒排索引，同时匹配：
  - 模块标题（如“推理深度”）
  - 技术关键词（如 `reasoning_effort`, `yolo`, `proxy`, `mcp`）
  - 底层 RPC 方法名（如 `config.set`, `model.save_key`）
- **即时响应**：
  - 左侧 12 大分类自动收起无关项，仅保留命中的类别并显示匹配条数徽章（如 `模型路由 (3)`）；
  - 点击或按回车直达右侧对应锚点卡片，卡片产生 **1.2 秒翡翠微光呼吸脉冲（Emerald Pulse Border）**，指引视觉焦点。

### 1.3 极客双模：可视化表单 ↔ YAML 源码直通 (Visual Form ↔ YAML Direct Sync)
- **顶栏分段控制器**：`[ 📋 交互表单 | ⚙ YAML 源码 ]`，随时可无损切换；
- **YAML 视图特性**：
  - 使用 Monaco / Prism 渲染等宽代码编辑器，自动定位到当前所选模块对应的 YAML 配置段；
  - 支持直接在编辑器里手改 YAML 配置，点击保存时调用网关 `config.set` 进行服务端 Pydantic 校验；
  - 若语法错误，行内即时标红波浪线并提示具体行号，杜绝配置损坏。

### 1.4 即时自动保存与脏值回退 (Auto-save with Dirty State Reversal)
- 摒弃死板的“所有设置填完最后点确定保存”的旧时代做法；
- 单项配置失焦（onBlur）或开关切换（onChange）时，**微任务防抖 200ms 自动落盘**；
- 正在保存时控件右侧显示极轻的加载微动效，保存成功后变成静默淡出的绿勾 `✓`；
- 每个卡片悬停时右上角均保留 `[ ↺ 还原默认 ]` 快捷动作。

## 二、 视觉设计系统与 Design Tokens 强对齐 (Visual Tokens Alignment)

所有样式严格使用工作区 29-color Tokens 与尺寸基准，**严禁硬编码任何裸色值**：

| UI 视觉要素 | 语义 Token 定义 | 物理渲染值 (Dark Mode) | 视觉感受与交互意图 |
|---|---|---|---|
| **主背景遮罩 (Overlay)** | `var(--bg-overlay)` | `rgba(0, 0, 0, 0.72)` | 毛玻璃 `backdrop-filter: blur(24px)`，彻底隔绝背景干扰 |
| **模态卡片基底 (Dialog Body)** | `var(--bg-card)` | `#0C0C0C` | 纯黑深邃底色，营造沉浸式极客控制台 |
| **左侧导航栏底色 (Sidebar)** | `var(--bg-subtle)` | `#111111` | 与主工作区分离层级，弱对比分割 |
| **右侧设置卡片 (Setting Row)** | `var(--bg-surface)` | `#161616` | 悬浮卡片感，带 10px 内部圆角 |
| **卡片悬浮态 (Row Hover)** | `var(--bg-surface-hover)` | `rgba(255, 255, 255, 0.04)` | 极其细腻的触控/鼠标悬浮微提亮 |
| **边框与分割线 (Borders)** | `var(--border-subtle)` | `rgba(255, 255, 255, 0.07)` | 1px 细线，不喧宾夺主 |
| **高亮主色 (Accent / Focus)** | `var(--accent)` | `#D97706` (Amber 琥珀暖金) | 焦点选中框、主按钮、激活 Tab 底边线 |
| **正常与成功指示 (Success)** | `var(--status-online)` | `#10B981` (Emerald 翡翠绿) | 网关连接正常、保存成功、在线指示点 |
| **高危与错误指示 (Destructive)**| `var(--status-error)` | `#EF4444` (Ruby 宝石红) | 阻断危险命令、删除 Bot、出厂重置警告 |
| **主标题字阶 (Heading)** | `var(--font-sans)` | `14px / 600 SemiBold` | 紧凑克制，无夸张大字，高密度专业感 |
| **正文说明字阶 (Description)** | `var(--text-muted)` | `12px / 400 Regular` | 辅助说明文本，透明度 60% 弱化 |
| **代码与契约字阶 (Code / Mono)**| `var(--font-mono)` | `11px / JetBrains Mono` | 显示 RPC 方法名、配置键、API 密钥掩码 |

## 三、 响应式视口与移动端 Capacitor 8 容器适配 (Mobile Parity Spec)

在手机与平板视口（$< 768\text{px}$）下，模态卡片自动降解为**全屏沉浸式页面**，对标 iOS 原生 Settings 体验：

### 3.1 移动端核心适配三铁律：
1. **触控热区绝对不小于 44pt**：所有 Switch 开关、下拉选框与返回按钮的物理点击区域保证 `min-height: 44px; min-width: 44px;`；
2. **边缘滑动手势导航 (Edge Swipe Back)**：支持从屏幕最左边缘向右平滑滑动手势退出二级详情页，与 iOS 原生转场动画无缝契合；
3. **软键盘与安全区避让**：在配置 API Key 呼出系统软键盘时，列表自动向上增加 `padding-bottom: var(--oc-kb-scroll-inset)`，杜绝输入框被键盘遮挡。

## 五、 质量与性能守护不变量 (Engineering Invariants Checklist)

1. **零内存泄漏与停表机制**：当设置弹窗关闭或折叠时，所有正在运行的后台探针（如 MCP 探活、心跳 Ping、沙箱画面拉流）必须立即调用 `AbortController.abort()` 或注销定时器；
2. **样式无抖动重排 (No CLS)**：左右双栏的宽度使用严格固定尺寸（`230px` + 弹性剩余宽），图片与图标预留确定像素尺寸，禁止加载时产生界面跳跃；
3. **分层架构红线**：所有设置组件（`packages/ui`）严禁直接导入平台相关 API 或裸写 `fetch/WebSocket`，统一通过 `packages/core` 暴露的 Store 与 Client 驱动。
